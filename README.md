# DaikonPalette

画面の左端に常駐する単語パレットです。単語のボタンを押すと、今使っているアプリ（メモ帳・Word・Teams・Outlook など）のカーソル位置に文字が入ります。テンプレートのボタンを押すと、テンプレートがクリップボードにコピーされます。

- 入力モード（**あ 日本語** は緑、**A 英数** は赤）が常に見えます
- 文字が入るアプリ（入力先）が常に見えます
- 「＋ メモ」で、日付.時刻.txt のメモをすぐに作れます

## ビルド（インストール不要）

1. `build.bat` をダブルクリック
2. Windows 付属の `csc.exe`（.NET Framework 4.x）でビルドされ、`dist\DaikonPalette.exe` ができます
3. `dist` フォルダを好きな場所（例: `C:\Tools\DaikonPalette`）に置いて `DaikonPalette.exe` を実行します

.NET SDK や Visual Studio は不要です。`build.bat` を再実行しても、`dist\data\` の中のファイル（単語・テンプレート・メモ）は上書きされません。

`dist\data\` に書き込むので、`dist` は `C:\Program Files` ではなく、自分で書き込める場所に置いてください。

## 使い方

| 場所 | 内容 |
|---|---|
| 左上 | 今使っているアプリの入力モード（あ 日本語 = 緑 / A 英数 = 赤 / ? 不明 = 灰色） |
| 右上の「«」 | パレットを隠す（左端の細い帯になる）。帯の「»」で元に戻る |
| 入力先 | 文字が入るアプリ |
| ＋ メモ | `data\memo\` に `20261024.1012.txt` のような空のメモを作り、メモ帳で開く |
| メモフォルダ | `data\memo\` をエクスプローラーで開く |
| 中央の単語（灰色） | 押すと入力先のカーソル位置に入る |
| 中央のテンプレート（青） | 押すとクリップボードにコピーされる。貼り付けたい場所で Ctrl+V |
| 単語を編集 / テンプレートを編集 | `data\palette.json` / `data\templates.json` をメモ帳で開く |
| 一番下の「終了」 | DaikonPalette を終了する |

- 入力したい場所をクリックしてカーソルを置いてから、パレットのボタンを押します。パレットを押しても入力先のアプリはアクティブなままなので、そのままキーボードで続きを打てます
- 他のアプリを最大化しても、パレットの部分は避けて表示されます
- 使わないときは「«」で隠せます。隠している間は幅 32px ほどの帯になり、入力モード（あ / A）だけが表示されます。アプリは起動したままです
- スライドショーや動画を全画面にしている間は、パレットは隠れます
- 二重起動はしません。タスクバーには出ません

## 単語・テンプレートの編集

「単語を編集」「テンプレートを編集」でメモ帳が開きます。保存するとパレットにすぐ反映されます（再起動は不要）。

### `data\palette.json`（単語）

```json
{
  "会議": ["議事録", "打ち合わせ", "決定事項"],
  "記号": ["■ ", "【{{cursor}}】"]
}
```

`"グループ名": ["単語", "単語", ...]` の形で書きます。グループの順にパレットに並びます。

### `data\templates.json`（テンプレート）

```json
{
  "TODO": [
    "■ TODO（{{date}}）",
    "・{{cursor}}"
  ]
}
```

`"テンプレート名": ["1行目", "2行目", ...]` の形で書きます。配列の 1 つが 1 行になります。

### 使える書き方

| 書き方 | 入る文字 |
|---|---|
| `{{date}}` | 日付（2026/10/24） |
| `{{time}}` | 時刻（10:12） |
| `{{datetime}}` | 日付と時刻（2026/10/24 10:12） |
| `{{weekday}}` | 曜日（土） |
| `{{cursor}}` | 入力後のカーソル位置（例: `【{{cursor}}】` なら括弧の中） |

- `$` で始まる項目（`"$comment"` など）は説明用で、パレットには出ません
- JSON の書き方が間違っていると、パレット下部に赤い文字でエラーが出ます。直して保存するまでは、前の内容のまま表示されます
- ファイルを削除すると、次に「編集」を押したときに初期の内容で作り直されます

## 入れ方

**テンプレート**はクリップボードにコピーするだけです。長い文章をキー入力で送ると、アプリによっては途中で止まることがあるためです。貼り付けたい場所で Ctrl+V を押してください（何度でも貼れます）。`{{cursor}}` はコピーのときは取り除かれます。

**単語**は、どのアプリでもキーボードで打ったのと同じ方法で入れます（クリップボードは使いません）。
単語に改行を含めた場合だけ、入力先に合わせて入れ方を変えます。

| 入力先 | 入れ方 | 理由 |
|---|---|---|
| メモ帳 | キー入力（Enter で改行） | そのままで問題ない |
| Word、Outlook | 貼り付け | キー入力だと「・」が箇条書きになるなどオートフォーマットが効くため |
| Teams、その他 | キー入力（Shift+Enter で改行） | Enter だとメッセージが送信されてしまうため |

貼り付けのときは、クリップボードの内容を一時的に置き換え、0.5 秒後に元に戻します。

```
DaikonPalette.exe
README.md
LICENSE.md
data\
├─ palette.json     単語
├─ templates.json   テンプレート
└─ memo\            「＋ メモ」で作ったメモ
```

## 注意

- 管理者として実行しているアプリには、Windows の制限で文字を入力できません
- メインのモニターの左端に表示されます
- 入力モードの表示は、アプリによっては「?」になることがあります（IME の状態を取得できない場合）
- 改行を含む単語を Word・Outlook に入れるときは、クリップボードを一時的に使います。Office でコピーした表など複雑な内容は、完全には元に戻らないことがあります
- PC の起動時に自動で起動したい場合は、`DaikonPalette.exe` のショートカットを `shell:startup`（エクスプローラーのアドレス欄に入力）に置いてください

## 開発者向け

```
DaikonPalette.sln
├─ build.bat              利用者向けの正式ビルド（csc.exe / C# 5）→ dist\
├─ Directory.Build.props  Rider でのビルド出力を build\ にまとめる
├─ .editorconfig          コーディング規約
├─ data\                  初期の palette.json / templates.json（build.bat が dist\data にコピー）
├─ docs\DESIGN.md         設計
└─ src\
   ├─ DaikonPalette.csproj  Rider 用（net48 / LangVersion 5）
   ├─ Program.cs            起動・二重起動防止
   ├─ PaletteForm.cs        パレットの画面・入力処理
   ├─ AppBar.cs             画面左端への常駐（SHAppBarMessage）
   ├─ InputSender.cs        キー入力の送信（SendInput）
   ├─ ImeReader.cs          入力モードの読み取り（WM_IME_CONTROL）
   ├─ PaletteData.cs        JSON の読み書き・メモ作成・プレースホルダー
   ├─ NativeMethods.cs      Windows API の宣言
   ├─ AssemblyInfo.cs       バージョン
   └─ Resources\
      ├─ app.png            アイコンの元画像
      └─ app.ico            exe のアイコン（app.png から作成）
```

### ルール

- Windows 付属の csc.exe は C# 5 までなので、C# 6 以降の構文（`$"..."`、`?.`、`=>` で書くメンバー、`out var`、`nameof` など）は使わない。Rider 用の csproj は `LangVersion=5` なのでエラーになる
- `.cs` は UTF-8（BOM 付き）・CRLF。`build.bat` は ASCII 文字だけで書く
- 外部ライブラリは使わない（.NET Framework 付属のものだけ）
- バージョンは `src\AssemblyInfo.cs` で管理する
