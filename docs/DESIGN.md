# DaikonPalette 設計

## 1. 概要

画面の左端に常駐し、ボタンを押すと前面のアプリのカーソル位置に単語を入力する Windows 用の常駐アプリ。テンプレートはクリップボードにコピーし、貼り付けは利用者が Ctrl+V で行う。

日本語キーボードで分かりにくい入力モード（日本語 / 英数）と、文字が入るアプリ（入力先）を常に表示する。

### 方針

| 方針 | 内容 |
|---|---|
| 軽量 | Windows 付属の csc.exe でビルドでき、インストール不要。外部ライブラリを使わない |
| 邪魔をしない | パレットを押しても入力先のアプリからフォーカスを奪わない |
| 安全 | 入力先のアプリに合わせて入れ方を変え、意図しない送信や書式変更を避ける |
| オフライン | ネットワーク通信をしない |
| 編集しやすい | 単語・テンプレートはメモ帳で編集できる JSON。保存すれば即反映 |

## 2. 技術

| 項目 | 内容 |
|---|---|
| 対象 | Windows 10 / 11 |
| 言語 | C# 5（Windows 付属の csc.exe の上限） |
| 実行環境 | .NET Framework 4.x（Windows 標準） |

| ビルド | build.bat（利用者向け）、DaikonPalette.csproj（Rider での開発用） |

## 3. 主な仕組み

### 3.1 左端への常駐（AppBar.cs）

`SHAppBarMessage` で画面左端に AppBar として登録する。タスクバーと同じ仕組みで、他のアプリを最大化しても AppBar の領域を避ける。

- 幅は 240px（96 DPI 基準。DPI に合わせて拡大）。隠したときは 32px の帯になり、AppBar の幅も縮める（他のアプリが使える幅が広がる）
- 縦は作業領域（タスクバーを除く）に合わせる
- `ABN_POSCHANGED` で位置を合わせ直す
- `ABN_FULLSCREENAPP` で全画面のアプリ（スライドショー・動画）が開いている間は隠れる
- 終了時に `ABM_REMOVE` で登録を解除する

### 3.2 フォーカスを奪わない（PaletteForm.cs）

| 設定 | 目的 |
|---|---|
| `WS_EX_NOACTIVATE` | クリックしてもウィンドウがアクティブにならない |
| `WM_MOUSEACTIVATE` に `MA_NOACTIVATE` を返す | 子コントロールのクリックでもアクティブにならない |
| `ShowWithoutActivation` | 表示時にアクティブにならない |
| `WS_EX_TOOLWINDOW` | タスクバー・Alt+Tab に出さない |
| `WS_EX_TOPMOST` | 常に最前面（`TopMost` プロパティはアクティブ化を伴うことがあるため使わない） |
| `ControlStyles.Selectable = false` | ボタンがフォーカスを取らない |

パレットが前面にならないので、ボタンを押した時点の前面ウィンドウ（`GetForegroundWindow`）がそのまま入力先になる。300ms ごとに前面ウィンドウとプロセス名を記録し、「入力先」として表示する。

### 3.3 文字の入力（InputSender.cs）

**テンプレート**はクリップボードにコピーするだけで、入力先には送らない。長い文章を `SendInput` で送ると、アプリ（特に WebView2 を使う Teams・新しい Outlook）が処理しきれず途中で止まることがあるため。貼り付けは利用者が Ctrl+V で行う（いつ・どこに貼るかを利用者が決める）。

- 改行は CRLF に変換してコピーする
- `{{cursor}}` は取り除く
- コピーしたことを下部に 3 秒間表示する

以下は**単語**の入力。

`SendInput` の `KEYEVENTF_UNICODE` で 1 文字ずつ送る。IME や キーボード配列に左右されず、サロゲートペア（絵文字・𠮷 など）も送れる。

| 入力先（プロセス名） | 1 行 | 複数行 |
|---|---|---|
| notepad | キー入力 | キー入力（Enter） |
| winword / outlook / olk | キー入力 | 貼り付け（Ctrl+V） |
| その他（ms-teams など） | キー入力 | キー入力（Shift+Enter） |

- **貼り付け**: クリップボードの内容を保存 → 文字列を設定 → Ctrl+V → 0.5 秒後に元に戻す。取り出せない形式は戻せない
- **カーソル位置**: `{{cursor}}` の後ろの文字数だけ ← キーを送る（改行・サロゲートペアは 1 回と数える）

### 3.4 入力モードの表示（ImeReader.cs）

前面ウィンドウのフォーカスのあるウィンドウ（`GetGUIThreadInfo`）から IME の既定ウィンドウ（`ImmGetDefaultIMEWnd`）を求め、`WM_IME_CONTROL` で状態を問い合わせる。IME の状態は変更しない。

| 状態 | 表示 | 色 |
|---|---|---|
| IME オン・ひらがな | あ 日本語 | 緑（#18B957） |
| IME オン・カタカナ | カ 日本語 / ｶ 日本語 | 緑（#18B957） |
| IME オフ・直接入力 | A 英数 | 赤（#E54848） |
| 全角英数 | Ａ 英数 | 赤（#E54848） |
| 取得できない | ? | 灰色（#808080） |

問い合わせは `SendMessageTimeout`（200ms）で、画面のスレッドを止めないよう別スレッドで行う。

### 3.5 データ（PaletteData.cs）

| ファイル | 内容 |
|---|---|
| `data\palette.json` | 単語。`"グループ名": ["単語", ...]` |
| `data\templates.json` | テンプレート。`"名前": ["1行目", ...]` |
| `data\memo\*.txt` | 「＋ メモ」で作るメモ。`YYYYMMDD.HHmm.txt`、重複時は `-2` `-3` |

- ファイルがなければ内蔵の既定を使う。「編集」を押したときに既定の内容でファイルを作る
- `data` フォルダを `FileSystemWatcher` で監視し、JSON が保存されたら 0.4 秒後に読み直す
- JSON の誤りはパレット下部に表示し、直すまでは前に読み込めた内容で表示を続ける（起動時から誤っている場合は内蔵の既定）
- `$` で始まるキーは説明用として無視する

プレースホルダー: `{{date}}` `{{time}}` `{{datetime}}` `{{weekday}}` `{{cursor}}`

## 4. 画面

```
┌──────────────────────┐
│ [あ 日本語]        [«] │  入力モード（緑 / 赤）・隠す
│ 入力先: notepad        │
│ [＋ メモ] [メモフォルダ] │
│                        │
│ 会議                   │  単語（灰色）
│ [議事録] [打ち合わせ] … │
│ …                      │
│ テンプレート            │  テンプレート（青・コピー）
│ [会議メモ] [TODO] …     │
│                        │
│ （エラー・お知らせ）     │
│ [単語を編集] [テンプレートを編集] │
│                        │
│ [        終了        ] │  幅いっぱい・地味な色（誤操作防止）
└──────────────────────┘

隠したとき（幅 32px の帯）:

┌──┐
│» │  表示に戻す
│あ│  入力モード（緑 / 赤）
│  │
└──┘
```

## 5. 制限事項

- 管理者権限で動いているアプリには入力できない（UIPI）
- メインのモニターにのみ表示する。DPI はシステム DPI（`SetProcessDPIAware`）
- IME で変換中にボタンを押した場合の動作は保証しない
- 自作の署名なし exe のため、環境によってはウイルス対策ソフトや SmartScreen に止められることがある
- PC 起動時の自動起動は、スタートアップフォルダへのショートカットで行う
